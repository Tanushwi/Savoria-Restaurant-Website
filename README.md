# 🍽️ SAVORIA — Fine Dining & Grill

A premium, highly animated, and fully responsive restaurant website built using pure **HTML, CSS, and Vanilla JavaScript**. 

### 🔗 [**View Live Website**](https://tanushwi.github.io/Savoria-Restaurant-Website/)

---

## ✨ Features

*   **🔐 User Authentication (Mock):** A beautiful glassmorphism Login/Signup screen that remembers the user locally.
*   **🛒 Smart Cart & Wishlist:** Add items to the cart, adjust quantities, and save favorites. All data is saved in `localStorage`, so it doesn't disappear on refresh!
*   **💳 Secure Checkout Flow:** A simulated payment gateway allowing users to choose between **Credit/Debit Card** or **UPI**. Includes a real-time processing animation.
*   **🎨 Wow-Factor Animations:** 
    *   Custom interactive cursor.
    *   Staggered scroll-reveal animations.
    *   Floating hero elements and "fly-to-cart" emoji animation.
    *   Marquee text sliders.
*   **📱 Fully Responsive:** Adapts seamlessly to mobile phones, tablets, and desktops.
*   **🍕 Dynamic Menu:** Filter dishes by category (Starters, Main Course, Pizza, etc.) with Veg/Non-Veg indicators.
*   **📍 Live Map Integration:** Embedded Google Maps location in the footer.

---

## 🚀 Tech Stack

*   **HTML5** (Semantic structure)
*   **CSS3** (Custom properties, Flexbox, CSS Grid, Keyframe animations, Glassmorphism)
*   **Vanilla JavaScript** (DOM manipulation, IntersectionObserver, LocalStorage, State management)
*   **Fonts:** Playfair Display & Outfit (via Google Fonts)
